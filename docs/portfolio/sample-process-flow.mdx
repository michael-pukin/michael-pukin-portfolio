## Overview

This sample is a process-flow diagram illustrating the relationships and dependencies between core payment transaction types within a merchant payment processing API. The diagram was designed to help developers and technical stakeholders understand transaction lifecycles, follow-on transaction requirements, and operational workflows.

## My Role

I analyzed transaction workflows, identified dependencies between transaction types, designed the process model, and created the supporting visual documentation.

## What It Demonstrates

Systems thinking, technical analysis, information design, and the ability to communicate complex technical workflows through concise visual documentation.
