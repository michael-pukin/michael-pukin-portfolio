## Overview

This sample is a developer integration guide for a hosted payment solution used in e-commerce applications. The guide covers implementation workflows, API interactions, callback handling, tokenization, fraud controls, testing, and production deployment.

This documentation was originally created for Moneris Solutions. The public version of the documentation is available through the Moneris Developer Portal.

## My Role

I worked directly with developers and product stakeholders to gather requirements, validate technical behavior, design the information architecture, author the content, coordinate reviews, and maintain the guide through multiple product releases.

## What This Demonstrates

Technical research, developer-focused communication, information architecture, SME collaboration, and the ability to explain a complex technical system clearly and accurately.
